A simple shell designed for the Linux operating system. I wanted to get into more low-level programming and figured a great project to bridge that gap would be a shell. Development has been very fun, though slower than I would hope, but alas. So far it only contains the basic features of a shell. next week i plan to add in some lesser used but still important simple features and environmental variables. after that, is an rc file, scripting, and a bunch of built in commands i don't have yet, and probably other stuff i don't know about, because quite frankly, not only has this been a learning experience for how shells are made and how they work, but also for how to use them in a more advanced manner. Running the file is pretty simple: just open the release and follow the guide there.
